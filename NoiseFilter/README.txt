Имеется 2 класса: генератор и фильтр шумов. Генератор содержит поток-producer, заполняющий массив 
дискретными значениями сигнала, в функцию которого подмешан шум. Класс фильтра шумов реализует пул потоков: 
один поток для синхронизации данных с генератором, остальные - потоки-workers. После получения сигнала 
от генератора, оный разделяется на одинаковые по длине массивы данных и передаются на обработку в очередь. 
Идея заключается в параллельной фильтрации сигнала сразу несколькими потоками для повышения скорости обработки.
После фильтрации дискретные отметки выводятся в консоль.

Инструментарий: std::thread, std::queue<>, std::future<>, std::functional<>, std::package_task<>, 
				std::shared_ptr<>, std::mutex, std::condition_variable, std::atomic<>.
